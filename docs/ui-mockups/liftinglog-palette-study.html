Palette study for the Workouts redesign

Three palettes shown on the same three screens. Ink takes its colours straight from the logo. Steel uses the same slate neutrals with a muted blue accent. Current is what's in lib/design-system/tokens.ts today, shown for reference. Each palette's contrast is calculated in the page against WCAG AA. Anything that fails is flagged in red.

What the contrast checks found

The current dark palette puts white text on a light red (the Delete button) and on a light blue (New Workout). Both come out around 2.5:1 and 3.2:1, well under 4.5:1. Whichever option you choose, I'd add an onDestructive text colour so the dark-mode Delete label uses dark ink.

How Ink marks state without colour

With no accent hue, "In progress" becomes a filled ink pill instead of blue text, and the active tab uses a heavier weight as well as the ink colour. The only colours left are gold for PBs and green, amber and red for status. "Best" becomes a quiet slate label.

What changes in code

The new values go in designColors in tokens.ts, plus one new role, onDestructive. NativeWind classes and rawColors pick up the change through DesignSystemProvider, so the Workouts screens need no component edits beyond the status pill.
