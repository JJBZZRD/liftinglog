The exercise page

This is the first of two mockup pages for round 2. It covers the exercise page (Record, History and Analytics), the rest timer and its new Settings defaults, and the two pages the exercise page opens: Set Info and Edit entry. Where a section has a real choice, the options are labelled A, B or C, and one is marked Recommended. Dialogs that only need converting to the existing design system are shown once, converted. Every screen is drawn at real Android dp and then scaled down. Example data is a Bench Press on the Push Day workout, as in round 1. Under each section, pick the options you want and add any comments. Your answers save as you go, and Claude can read them, so you only need to say "done" in the chat.

1 · Page shell

Header and the Record, History and Analytics switch

Today the page has a native header and a swipeable tab bar. Back from History or Analytics first jumps to Record, and only then leaves the page. Both options below make Back always leave, which matches every other page. The pin button stays at the top right.

2 · Record

Logging a set

The workout chooser becomes a single row showing whether that workout is in progress. The set form gets steppers (2.5 kg and 1 rep) around large values, and the rest timer moves into the same row as Add set. Recorded sets use workout detail's set rows, with BEST and PB badges. Tap a row to open Set Info, or the pencil to edit it. Delete moves into the Edit set sheet, so each row has one action instead of two.

3 · Record dialogs

Choose workout, edit, delete and clear

These are conversions to the shared sheet and confirmation dialog. There is one behaviour change. Today, tapping a workout in the chooser moves the entry and its sets at once. The sheet now waits for "Use Push Day", like the 1RM formula sheet. The time field in Edit set keeps the Android system time picker.

4 · Rest timer

One duration control, used in two places

Each exercise remembers its own rest time, and exercises without one use 1:30. The same duration control sets an exercise's rest time in the Rest timer sheet (long-press the timer button, or tap it while it runs) and the default in Settings. While the timer runs, the button turns green, because green means "happening now".

5 · History

Past sessions of this exercise

Each session gets the Workouts metric-strip treatment. Its three round icon buttons (view, edit, delete) go into a ⋯ menu. The filters move out of the collapsible panel: search stays on the page, and everything else goes in a sheet behind the filter button, whose badge counts the active filters.

6 · Analytics

Chart, controls and session details

The chart is drawn in Ink: a 2 dp ink line and dots, gold rings for PBs, and a dashed grey trend. Tapping or releasing a scrub on a point opens the session details as a bottom sheet in portrait. In landscape fullscreen, they open as a side panel so the chart stays visible.

7 · Set Info

One set: its note and video

Set Info opens from set rows on workout detail, Record, History and the session sheet. In the MVP build it is fully reachable, including linking a video from the gallery. Its "Video options" native alert becomes a sheet.

8 · Edit entry

Editing a past entry

This opens from History and the session sheet. The date, set changes and new sets are drafts, saved together by Save changes. Notes save straight away from their own sheet, as they do today. The page fixes two gaps. Leaving with unsaved set changes now asks before discarding them, where today only note drafts are guarded. A failed save now shows a message, where today it fails silently.

Decisions for you
  1. Page shell (1): A, the segmented control under a large title, or B, the compact header with underline tabs.
  2. Pins (1): since the pinned-exercises overlay was removed in round 1, pinning has no visible effect anywhere in the MVP. Remove the pin button, or show pinned exercises as a group at the top of the Exercises library (page B would mock it)?
  3. Record layout (2): A, the form above the recorded sets, or B, the sets above an entry panel docked at the bottom. Also: keep the ± steppers, or plain fields as today?
  4. Choose workout (3): is it OK that choosing a workout now waits for "Use …" instead of moving the entry immediately?
  5. Rest timer (4): A, the stepper with presets, or B, the minute and second wheels. The Settings default is part of this round. "Start after each set" would be new behaviour. Include it, or leave it out?
  6. History (5): A, the metric-strip session cards, or B, compact rows that open the session sheet. The filters go in a sheet either way.
  7. Analytics (6): A, the chart first with its controls in the card, or B, a controls list above the chart. The session details become a bottom sheet (a side panel in landscape) either way.
  8. Set Info (7): A, a full page, or B, a sheet.
  9. Edit entry (8): the notes move into their own sheets, "Add set" becomes a button that opens the set sheet, and the unsaved-changes guard now covers sets. OK?
